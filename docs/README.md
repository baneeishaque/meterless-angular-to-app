# Documentation

This folder contains the durable documentation for the Angular To-Do App.

## Index

- [Meterless Engines in the Angular To-Do App](meterless-fit.md) — what each engine does, where it lives, persistence keys, browser adaptations, and deliberate limits.
- [Testing Guide](testing/README.md) — testing entry point, quick commands, and current results.
- [Meterless Engines Testing Guide](testing/meterless-engines-testing-guide.md) — maximum-detail manual and automated test guide for the assistant, Scout, H-MEM, World Model, and Markovian.

## Documentation conventions

- Folder and file names use lowercase kebab-case, except the industry-standard `README.md`.
- Each guide states its scope, prerequisites, commands, expected results, and troubleshooting.
- Code references use repository-relative paths so the docs survive machine changes.
- Public docs avoid local-only scratch paths and session identifiers.
